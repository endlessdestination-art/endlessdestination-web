# Endless Destination — GitHub Pages

Landing page for **Endless Destination**, a spooky/cinematic AI reels brand. The page includes buttons for PixVerse, DomoAI, Instagram and email.

## Links currently configured

- Instagram: `https://www.instagram.com/endlessdestination.art/`
- Email: `mailto:endlessdestination.art@gmail.com`
- PixVerse: placeholder homepage — replace it with your affiliate link in `script.js`.
- DomoAI: placeholder homepage — replace it with your affiliate link in `script.js`.

## Before publishing

Open `script.js` and replace the PixVerse and DomoAI URLs with your real affiliate URLs. Instagram and email are already configured.

## Upload to GitHub

1. Go to GitHub and sign in.
2. Click **New repository**.
3. Give it a name such as `endlessdestination-web`.
4. Create the repository.
5. Open the repository and choose **Add file → Upload files**.
6. Upload everything inside this folder, keeping the `assets` folder intact.
7. Click **Commit changes**.
8. Go to **Settings → Pages**.
9. Under **Build and deployment**, select **Deploy from a branch**.
10. Select the `main` branch and `/ (root)`.
11. Save.
12. GitHub will generate your Pages URL after deployment.
